# SowSure – Smart Crop Planning Assistant

SowSure is an AI-powered web platform designed to empower small and marginal farmers with intelligent crop cycle planning, localized agricultural support, and simplified access to critical farming insights. Developed as part of a hackathon initiative, the application combines agricultural best practices with modern AI and web technologies to solve real-world challenges in Indian agriculture.

# SowSure - AgriN and Regenerative Agricultural Intelligence

SowSure is a multilingual agricultural intelligence platform for small and marginal farmers. It is our response to the **BRICS AgriN** theme of **Cooperation**: making data-driven, climate-resilient farming guidance easier to access while creating a foundation for shared agricultural data models across emerging economies.

The project preserves the original Sowsure crop-planning experience and extends its direction toward regenerative agriculture, localised agro-advisories, and interoperable digital public infrastructure.

## Problem

Farmers across emerging economies often lack timely access to:

- Soil health and field-condition insights
- Satellite and vegetation data
- Local weather forecasts and climate signals
- Crop disease diagnosis and early action guidance
- Regenerative crop, rotation, and intercropping recommendations

Without these tools, decisions depend on incomplete information. The result can be crop failure, soil degradation, income loss, and greater pressure on food security. Fragmented agricultural data also makes cross-border learning and cooperation difficult.

## Solution

SowSure provides a practical interface for AI-assisted agricultural guidance. The current experience includes:

- Farm-input-based crop planning and recommendations
- Regenerative rotation, intercropping, and soil-care guidance
- Disease diagnosis through the crop health module
- Market price visualisation and local resource discovery
- Farm calendars and task reminders
- Map-based agricultural information
- Multilingual support for English, Hindi, Tamil, and Telugu
- Helpline and feedback workflows for farmer support

The product is designed to grow into a shared digital agriculture network that can combine local farm information with satellite data, soil analytics, weather forecasting, and models that can be adapted across BRICS countries.

## BRICS AgriN Alignment

- **Cooperation:** Support shared knowledge, models, and agricultural data practices across regions.
- **Regeneration:** Encourage healthier soils, crop diversity, efficient water use, and resilient farm planning.
- **Localisation:** Present useful guidance in the farmer's language and context.
- **Interoperability:** Keep the platform modular so future country-specific data services can connect to the same experience.
- **Food security:** Help farmers make earlier, better-informed decisions under changing climate conditions.

## Tech Stack

- React 19 and React Router
- Vite
- Tailwind CSS
- Leaflet for maps
- Chart.js and Recharts for data visualisation
- i18next and react-i18next for localisation

## Getting Started

Requirements: Node.js 18 or newer and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. The other available commands are:

```bash
npm run lint
npm run build
npm run preview
```

## Project Structure
